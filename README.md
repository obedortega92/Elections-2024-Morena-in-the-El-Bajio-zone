The Morena electoral performance in the "El Bajío" 2024
These maps and plots are part of chapter analyzing the electoral performance of the Morena party in the 2024 elections, particularly in "El Bajío" region. This area includes the states of Aguascalientes, Guanajuato, Jalisco, Michoacán, Querétaro, San Luis Potosí,and Zacatecas. 
The project highlights that Morena faces challenges in winning gubernatorial races, mayoral offices, and majorities in local congresses across the region.
I extracted data from the National Electoral Institute (INE) and the Local Public Electoral Bodies (OPLES) websites to create bar and line charts, maps, and tables that illustrate Morena's the electoral perfomance.
This analysis was conducted using Python and the following libraries: Pandas (data manipulation), Matplotlib (visualization), NumPy (numerical computing), Folium and GeoPandas (geospatial analysis and mapping).
